# RADAR R0.1F2D — competition profiling foundation

Baseline F2C 7188c786d84d362578f9497bdae936232600584b: C3 failed command p95 degradation 102.6346564109792%, 2.029 to 4.112 ms; 36 mixed reads, p95 13.238 ms. F2C calendar and full PostgreSQL were still in progress when this candidate was prepared. No inference of a lock or CPU cause from timings alone.

New post-run profiler recomputes nearest-rank percentiles from raw samples and validates the six existing counterbalanced command blocks (40 commands per block), arm aggregation and lock sample/read counts. It parses actual EXPLAIN JSON recursively; records relation/index, estimated/actual rows, loops, inclusive time, buffers, spills and filtered rows. Parent/child metrics are inclusive and not summed. It reports largest read p95 and mixed degradation even on a failed test; insufficient evidence is INCOMPLETE, not a successful workload. Low mixed-reader sample count is flagged, not waived. The two CI jobs run Python self-tests and profiler after measured workload, including on failure, and publish competition-profile.json in the existing artifacts. No change to command, read, identity, isolation, sample schedule, database or SLA. Diagnostic output is not an admission verdict.
